# Menu DEBUG

A partir da v0.09.04, a aba DEBUG fica disponível diretamente no menu do
port. Abra com **L + R + Start** e use **L/R** para alternar entre CHEATS,
GAMEPLAY e DEBUG.

A aba inclui atalhos de minigames, cenas gravadas, profiler e testes A/B.
Não é necessário criar `debug_menu.txt` nem alterar arquivos no cartão.
